Setup

One-for-one with the Discord developer portal — token + guild ID and you're live

1 · Application

Open developer portal ↗

Portal → your app → General Information → Application ID → copy. This builds your invite link and the deep-links on this page.

2 · Bot token + intents

Open Bot page ↗

Write-only — stored server-side, never shown again. On the SAME Bot page, flip both privileged switches (Discord has no API for these two — it has to be you): MESSAGE CONTENT INTENT and SERVER MEMBERS INTENT. Skipped = the bot can't log in ("disallowed intents"). Reuse the token of the bot already running your server — one app can do slash commands and this tracking at once.

3 · Invite the bot

Invite to your server ↗

Read-only permissions (View Channels + Read Message History). Lights up once the Application ID is saved. Skip if the bot is already in your server.

4 · Guild

Once connected, the bot's servers list here — tap one to fill this in. Empty = track every server the bot is in.
